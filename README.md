# bioscan
Développement d’une application permettant d’analyser les informations des produits grâce au scan de leur code-barres, afin de faciliter l’accès aux informations sur leur composition et leurs caractéristiques. Le projet vise à aider les utilisateurs à faire des choix plus éclairés grâce aux technologies numériques.
